IF SOMETHING STILL FAILS
Xogot 1.7.12+ prints the launch-failure reason on screen; the Output pane
also prints these lines when boot works:
   [LEVERAGE v2.5.0] boot start | Godot ... | renderer=mobile | OS=...
   [LEVERAGE] boot cards done -> main menu
Send whatever appears (or the Xogot error panel text) back with your
iPhone model, iOS version and Xogot version. No card at all = delivery
problem (tell us how you opened it); cards then crash = send the error.
If even this project fails, try LEVERAGE_hello_diag_project.zip (a 6 KB
zero-dependency project) — if hello also fails, the problem is the
Xogot install/device, not the game.
